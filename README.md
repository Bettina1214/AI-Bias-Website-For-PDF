# AI Bias Lab

### 交互式网站展示页面

本项目是一个关于 **大型语言模型（LLM）偏见研究** 的交互式科普网站，基于我的研究成果构建。

## 🔍 网站功能

- **体验AI偏见**：通过4个交互实验（任务切换、模型对比、关键词替换、形容词擦除），让用户亲自感受AI在不同场景下的偏见表现
- **矫正AI偏见**：提供防御性提示词生成器，并介绍前沿的去偏见研究方向
- **资源下载**：提供触发词列表、防御性提示词模板、论文摘要等材料

## 📄 研究成果

本网站基于以下研究：

- 主论文：《Shallow Lexical, Deep Source: A Hierarchical Examination of LLM Bias in News Evaluation》
- 发现：LLM偏见是分层的——词汇偏见浅层且可纠正（防御提示词可缓解85%），信源偏见深层且顽固
- 扩展：通过GloVe词向量扩展 + AI词级别验证，构建了偏见触发词列表
- 验证：通过人机对比实验，验证了偏见来源于训练数据
